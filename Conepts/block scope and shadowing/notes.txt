Shadowing in JS:-
----------------

If we create same variable outside of block

var a  = 100;
{
var a = 10;
}
console.log(a); // 10

a 10 is shadowing of a 100. also 100 overwrited by 10

 let b = 20;
{
	let b  = 200;
}

console.log(b);

b 200 is shadowing of 20. but not overwrite.
Because. b = 20 is in special memory script scope in temporal dead zone.
b = 200 is in block scope.

Shadowing also in function also.
const c  = 10;
function x() {
	const c  = 100;
	console.log(c); // 100
}
console.log(c); // 10
